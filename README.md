# Neurovant Technology website

The public website for Neurovant Technology, an independent studio exploring ideas in progress. Neurofit is presented as a concept under exploration rather than a launched product.

## Local development

```bash
npm install
npm run dev
```

## Validation and production build

```bash
npm run check
npm run preview
```

The Vite build uses relative asset paths so the generated `dist/` directory works beneath the GitHub Pages `/landing-page/` path.
